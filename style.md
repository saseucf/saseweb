# UCF SASE styling reference

The canonical standard is now [DESIGN.md](DESIGN.md). It distinguishes measured Figma styles, adopted hero behavior, and proposed defaults for unfinished screens.

Use the [visual specimen](docs/design/index.html) to compare light and dark styling, and the [reference tokens](docs/design/tokens.css) for reusable values. These documentation files are not imported by the application.

The earlier guide mixed implementation details with Figma direction. In particular, Orbitron/Roboto Mono, gray cream, sand yellow, and the old navigation breakpoint should not be treated as Figma requirements. Consult DESIGN.md before the next frontend cleanup.

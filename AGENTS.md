# Repository workflow

- Create new feature branches as `feature/<short-kebab-case-description>` (for example, `feature/events-mobile-layout`). This is the team's requested naming convention; use it instead of the default `codex/` prefix.
- Follow an explicitly requested branch name when the user supplies one.
- Existing branches and pull requests can keep their current names. Do not rename them solely to apply this convention retroactively.
